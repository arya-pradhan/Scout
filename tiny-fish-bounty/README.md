# Scout: app code

This folder is the Scout app (TypeScript, Photon Spectrum + TinyFish + Claude).
**The full write-up, setup and architecture are in the [root README](../README.md).**

Quick start:

```sh
npm install
cp .env.example .env   # fill in the keys (see the root README)
npm run chat           # try Scout in your terminal
npm run dev            # run it on iMessage
npm test               # offline tests (no network, no credits)
```
